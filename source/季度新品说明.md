# Liang Ping：日常回响

Atelier Onde 第四季度新品视觉提案。使用提供的五张原始摄影：第一章为留白戒指、连缀链饰、跃影吊坠；第二章为来电戒指和脉冲手链。首页呈现的是从这五幅摄影里提取的真实首饰，不是另画的模型。

## 观看

直接用浏览器打开交付的 **Liang Ping - 日常回响.html**。图片、样式与交互都在文件里，断网也能观看。不需要安装工具，也不要用只显示文件内容的文本预览器。

首页可用横向拖动、手机横滑、左右键或右侧章节号换章。点击作品，首饰从展台回到自身在原图里的位置。向下滚动依次看摄影、纸上习作、局部；向上滚动可复原。底部的三个刻度也可直接定位。关闭作品会回到所属章节；菜单提供五件作品的直接入口。声音默认关闭。

## 下一季如何复用

| 要修改的内容 | 位置 |
| --- | --- |
| 名称、章节顺序、中文文案、音高、照片 | `src/components/sites/onde/content.mjs` |
| 原始摄影及轻量布面 | `public/sites/onde/` |
| 首饰轮廓和镂空 | `scripts/onde-objects.mjs`。修改原图坐标中的路径，运行 `node scripts/onde-objects.mjs`，同时生成透明图和用于转场的定位表。 |
| 每件作品的镜头焦点、特写倍率及纸上颜料 | `MaterialStudy.tsx` 中的 `studies`；焦点坐标按原始图片宽高归一化。 |
| 首页构图、字号、控件、安全间距 | `src/app/globals.css` |
| 布面受光、金属投影、作品归位 | `ClothLight.tsx`、`Gallery.tsx`、`silverPass.ts` |
| 纸面笔触和三个滚动阶段 | `materialPlate.ts`、`MaterialStudy.tsx`、`MaterialStudy.module.css` |

未写全路径的组件位于 `src/components/sites/onde/`。换照片时，要一起校准轮廓和镜头焦点；只换图片文件无法自动识别新首饰。浏览器不支持光场时会显示静态布面；系统要求减少动态时，页面保留原图和文字，取消固定滚动镜头。

## 启动与导出

需要 Node.js 24 或更高版本：

```sh
npm ci
npm run dev
```

改好后运行 `npm run offline -- "Liang Ping - 日常回响.html"` 重新导出单文件。`npm test` 检查章节和手势，`npm run check` 检查代码并构建。安装了 Chrome 时，可对启动后的地址运行 `PREVIEW_URL=http://127.0.0.1:3000/ npm run test:browser`。

参考 Cartier 的选件和分幕体验，未复制其专有三维珠宝模型、影片或原声。这是供本地演示和迭代的项目；部署公网前请复核图片授权及模板依赖安全。
