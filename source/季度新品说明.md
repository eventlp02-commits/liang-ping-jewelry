# Liang Ping：日常回响

Liang Ping 第四季度新品视觉提案。使用提供的五张原始摄影：第一章为留白戒指、连缀链饰、跃影吊坠；第二章为来电戒指和脉冲手链。首页呈现的是从这五幅摄影里提取的真实首饰，不是另画的模型。

## 观看

直接用浏览器打开交付的 **Liang Ping - 日常回响.html**。图片、音乐、样式与交互都在文件里，断网也能观看。

首页可横向拖动、手机横滑、左右键或点击章节号换章。「探索作品」是可点击的入口。点击作品，首饰从展台回到原图的位置；移动指针时，首饰高光与阴影随之改变。

滚动或拖动底部进度线依次观看摄影、纸上习作、局部特写，三个图标可直接定位。左右箭头切换作品，展开图标打开原图；原图支持放大、拖动、双击与触屏捏合。关闭作品会回到所属章节。

首次选择作品时播放附件《Someone In The Crowd》，切换作品不中断，暂停后保持暂停。右下角控制播放和音量。原有解释性段落已在组件内注释，文案数据仍保留以便复用。

## 下一季如何复用

| 要修改的内容 | 位置 |
| --- | --- |
| 名称、章节顺序、保留文案、照片 | `src/components/sites/onde/content.mjs` |
| 原始摄影及轻量布面 | `public/sites/onde/` |
| 首饰轮廓和镂空 | `scripts/onde-objects.mjs`。修改原图坐标中的路径，运行 `node scripts/onde-objects.mjs`，同时生成透明图和用于转场的定位表。 |
| 镜头焦点、图片显示比例及纸上颜料 | `MaterialStudy.tsx` 中的 `studies` 和 `fit`；焦点坐标按原始图片宽高归一化。 |
| 首页构图、字号、控件、安全间距 | `src/app/globals.css` |
| 布面受光、金属投影、作品归位 | `ClothLight.tsx`、`Gallery.tsx`、`silverPass.ts` |
| 纸面笔触和三个滚动阶段 | `materialPlate.ts`、`MaterialStudy.tsx`、`MaterialStudy.module.css` |
| 配乐、默认音量、播放状态 | `Soundtrack.tsx`、`public/sites/onde/someone-in-the-crowd.mp3` |
| 原图查看与缩放 | `DetailViewer.tsx`；核心缩放使用 Panzoom |

未写全路径的组件位于 `src/components/sites/onde/`。换照片时，要一起校准轮廓和镜头焦点；只换图片文件无法自动识别新首饰。系统要求减少动态时，页面保留原图、名称与查看功能，取消固定滚动镜头。

## 启动与导出

需要 Node.js 24 或更高版本：

```sh
npm ci
npm run dev
```

改好后运行 `npm run offline -- "Liang Ping - 日常回响.html"` 导出含音乐单文件，或 `npm run publish:build` 生成 GitHub Pages 网页及独立配乐。`npm test` 检查章节和手势，`npm run check` 检查代码并构建。安装 Chrome 后，可对启动后的地址分别运行 `PREVIEW_URL=http://127.0.0.1:3000/ npm run test:browser`、`npm run test:quiet` 与 `npm run test:framing`。

参考 Cartier 的选件和分幕体验，未复制其专有三维珠宝模型、影片或原声。这是供本地演示和迭代的项目；部署公网前请复核图片授权及模板依赖安全。
